# Surface brief: work page

Scope: `/work/` ("Work"), plus the talks, posts, tags and 404 pages.
Visitor mode: Read. Detail pages (talk, post) read as documents.

Audience: Kubernetes maintainers, SIG peers and conference organizers checking what Anish shipped.
Job: see which features he carried through which releases, what else he maintains or created, and
every release, post and talk in date order; then open the KEP, PR, post or talk.
Proof: kubernetes/enhancements kep.yaml milestones and v1.N.0 tag dates (`data/ledger.yaml`,
generated by `make ledger`), kubernetes.io release posts, talk recordings, OWNERS, CODEOWNERS and
the SIG Auth README for roles. Nothing unverified is shown.
Constraints: only agent-primitives/sessions and aramase/kontxt under agent infrastructure; entries
stay short (name, role, one line, link); permalinks kept.

Direction: "changelog", chosen by Anish on 2026-11-06; it replaces "timing". The ledger data and
its sources are unchanged; the page reads it through a stepper and a timeline.

FIRST VIEWPORT: page head with jump links, then "How a Kubernetes feature ships" (Alpha, Beta, GA
in one line each) and the first feature rows: name, plain line, KEP, SIG, co-authors and PRs beside
an Alpha/Beta/GA stepper. A reached step shows release, month and post or talk links; a missing
stage below the highest reached says "Skipped"; anything above it, a GA target included, says
"Not yet".

Below: the SIG Auth co-chair entry, the Projects groups, and the timeline of every release, post
and talk by year, with All/Releases/Posts/Talks filters and a live count. Without JS every event
shows.
